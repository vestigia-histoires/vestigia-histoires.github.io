Privacy Policy

1. Who we are

VESTIGIA is a YouTube channel (@vestigia.histoires) operated by an individual. To publish its own videos, it uses an internal tool, the "VESTIGIA" API client, which connects to the YouTube API Services.

2. Who uses the API client

The API client is strictly private. It is used only by the owner of the VESTIGIA channel, for that channel. It is not offered, sold or distributed to any third party, and no other user signs in to it.

3. Information accessed through YouTube API Services

With the channel owner's authorization (Google OAuth 2.0), the API client accesses only the VESTIGIA channel in order to:

  • identify the connected channel (channels.list);
  • upload videos produced by VESTIGIA and set their title, description, tags and scheduled publication time (videos.insert);
  • cancel a scheduled publication (videos.update).

The API client does not access, collect, store or share any personal data of other YouTube users (no comments, subscribers, viewing history or analytics).

4. How the information is used, stored and shared

The only data stored by the API client are: the OAuth refresh token of the channel owner (kept in a configuration file on a private server, accessible only to the owner) and the IDs of the videos uploaded by VESTIGIA. This data is used solely to publish and manage VESTIGIA's own videos. It is never sold, shared with third parties, or used for advertising.

5. Cookies and device information

The API client does not use cookies and does not store, access or collect information on any user's device. This website does not use cookies or tracking.

6. Data retention and deletion

Stored video IDs are kept only as long as needed to manage VESTIGIA's own videos. The authorization can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, or upon request sent to the contact address below, the OAuth token and all stored data related to the YouTube API Services are deleted within 7 days.

Facebook, Instagram and TikTok

VESTIGIA also publishes its own videos to its own Facebook Page, Instagram account and TikTok account, through the official Meta Graph API and TikTok Content Posting API. The same private tool is used, only by the owner, only for these VESTIGIA accounts. It accesses only what is needed to publish: the identifier of the VESTIGIA Page and accounts, and the right to post videos and captions on them. It does not access, collect or store any data about other users (no messages, followers, comments or statistics of other people). The only data stored are the owner's access tokens, on a private server, and the identifiers of the published videos. They are never sold or shared. Deletion instructions: data-deletion.html.
