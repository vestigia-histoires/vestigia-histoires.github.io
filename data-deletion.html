Data deletion instructions / Instructions de suppression des données

Data deletion

VESTIGIA's publishing tool is private and used only by the owner of the VESTIGIA accounts. It stores no data about other Facebook, Instagram, TikTok or YouTube users.

The only data stored are the owner's own access tokens and the identifiers of VESTIGIA's published videos. To have them deleted:

  1. Remove the "VESTIGIA Publisher" app from your account settings (Facebook: Settings & privacy → Settings → Apps and websites; Instagram: Settings → Website permissions → Apps and websites; TikTok: Settings → Security → Manage app permissions; Google: security.google.com/settings/security/permissions).
  2. Or send a request to vestigia.histoires@gmail.com.

All related data is deleted within 7 days.

Suppression des données

L'outil de publication de VESTIGIA est privé et utilisé uniquement par le propriétaire des comptes VESTIGIA. Il ne conserve aucune donnée sur d'autres utilisateurs de Facebook, Instagram, TikTok ou YouTube.

Les seules données conservées sont les jetons d'accès du propriétaire et les identifiants des vidéos publiées par VESTIGIA. Pour les faire supprimer :

  1. Retirez l'application « VESTIGIA Publisher » des paramètres de votre compte (Facebook : Paramètres et confidentialité → Paramètres → Applications et sites web ; Instagram : Paramètres → Autorisations des sites web → Applications et sites web ; TikTok : Paramètres → Sécurité → Gérer les autorisations des applications ; Google : security.google.com/settings/security/permissions).
  2. Ou envoyez une demande à vestigia.histoires@gmail.com.

Toutes les données concernées sont supprimées sous 7 jours.
